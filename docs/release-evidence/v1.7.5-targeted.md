## 专项范围与证据

- 自定义服务：全参视频协议只通过明确协议元数据或用户选择启用；独立素材源由用户显式配置。
- 素材上传：保留原始字节，校验哈希、大小、类型、时长、来源与分片索引；每次 JSON 回执独立解析；非法上传 ID 不发送分片；批次失败不覆盖原始引用。
- 视频下载：完成结果中的根相对路径按 API 原站解析；凭据仍只随同源请求发送。
- 资产播放：视频和音频详情复用鉴权资源读取；浏览器实测验证 Blob 播放地址以及用户切换隔离。
- 原生验收：macOS 正式应用路径安装候选后，已有视频可播放且时间推进；不填后缀保存可得到 `.mp4`，保存文件与原视频哈希一致。合并 #80 后再次播放，升级前后资源、资产、任务与项目记录数量一致。保存入口在此次合并中未变。
- 更新续传：TLS 测试服务覆盖 Range、200 回退、416 重下、错误哈希、停止进展、父 context 取消、提前 chunked EOF 保留断点以及日志 URL 脱敏；签名和完整文件 SHA256 校验仍强制执行。
- 真实网络：候选更新器通过系统代理读取正式签名 feed，下载线上 v1.7.3 的 153977952 字节安装包并达到 ready。此检查没有安装旧版，也不等于 Windows 原生交互验收。
- 隐私：当前跟踪源码、macOS 主程序、CLI 与内置协议包扫描未检出被移除的供应商身份及私有域名。私有截图、原始日志、生产请求与账务标识不提交到仓库。
