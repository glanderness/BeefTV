## 已复现问题与修复

- 兼容目录只有 `supported_endpoint_types` 时，中文和不透明视频 ID 被识别为文本。按端点元数据识别用途，保留用户已有协议选择。
- 全参 2.0 / 2.5 的 JSON references、分片上传、同源鉴权原片下载不能套用 Sora multipart；新增明确白名单的插件和本地素材准备逻辑。
- 目录读取遇到 4 秒客户端超时，单独将 `/ai/models` 请求等待时间调整为 30 秒。
- 音频读取复用旧服务的 15 MiB 限制，可能拒绝或截断合法素材。使用老李专属有界读取，已知与未知体积均保留完整字节，超过 100,000,000 字节拒绝。
