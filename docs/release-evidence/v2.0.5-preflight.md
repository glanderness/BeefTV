## 失败一：思考界面断言

```text

```

旧日志没有保存该 11 文件批次的完整命令行，不能补造。下面是本轮的最小重放命令：

```sh
cd web
bun test test/assistant-stream-progress.browser.test.ts
```

未改动时独立运行：4 pass / 0 fail / 31 assertions。随后只在展开按钮点击前加入 `THINKING_GAP_MS * 2`（1200ms）的延迟，使用同一产品代码运行：

```sh
bun test test/assistant-stream-progress.browser.test.ts -t '思考默认折叠'
```

重现失败：`bodies.length` 期望 `> 1`，实际 `1`。这与上轮具体落点相邻，均是第一段在展开前已经被后续快照替换，采样器无法看到折叠区中并不存在的 DOM。产品默认折叠本来就不会渲染思考正文；固定每 600ms 发包、每 100ms 采样不能保证按钮及时展开。

修正只在测试替身内：发出首段后等待测试展开并采到首段，再经测试专用接口放行下一段；保留 1200ms 延迟重放，保留所有原有增量、默认折叠、终态前显示、正文分离及空思考清除断言，并增加首段阶段“没有第二段、仍在流式”的断言。没有延长超时、跳过用例或改产品展示逻辑。若产品真的不显示首段，测试会在放行前超时失败。

修正后同一文件：**4 pass / 0 fail / 33 assertions**。相邻验证：

```sh
bun test test/canvas-agent-assistant-stream.test.ts test/canvas-agent-assistant-wiring.test.ts test/canvas-image-recovery.browser.test.ts
```

结果：**45 pass / 0 fail / 2144 assertions**。原清理 hook 超时未复现，未修改 hook 超时标准。这里运行的是仓库已有的 Playwright 自动化测试；人工界面操作使用 Ego，没有用 Playwright 或 Safari 代替人工浏览器验收。
