# 多节点画布的局部更新

本轮保留 Wails、现有节点显示和交互，只减少无关节点渲染与整图计算。基线为 v2.0.3 `e13263c9`。没有改节点挂载预算、媒体质量、任务提交、业务版本校验或恢复规则。

## 改动

- 重新构建素材与提及映射时，复用内容未变的引用对象和数组，使节点已有的 memo 比较可以跳过无关更新。
- 空间索引保存连线端点身份，显示时读取最新节点。标题、提示词和任务状态更新不重建几何索引；位置、大小、类型、父节点、批次展开和分组折叠变化仍会使索引失效。
- 节点内容渲染与 memo 使用同一份自定义内容判定。普通镜头节点不再依赖实际未使用的页面渲染回调；工作流插槽等真正使用回调的节点仍会更新。
- 保存、离开页面和显式保存时，先比较数组与实体引用，只序列化需要核对的实体，避免反复序列化完整画布与助手会话。保留原有 JSON 比较结果和完整业务保存流程。

## 本机比较

生产模式 React、真实画布 hook/世界层/节点组件、合成本地图片与视频占位，不访问模型。基线由同一回放入口读取指定 Git 提交构建，候选读取当前源码。Chromium 154，961×880，DPR 1；两轮交换前后运行顺序，每轮预热 3 次、测量 25 次。下表为两轮“更新提交耗时中位数”的中位数，单位 ms。

| 初始节点 | 操作 | 基线 | 候选 |
| ---: | --- | ---: | ---: |
| 100 | 改一个标题 | 7.90 | 0.85 |
| 500 | 改一个标题 | 29.80 | 3.20 |
| 1000 | 改一个标题 | 31.90 | 3.00 |
| 500 | 每批追加 8 节点 | 25.15 | 3.75 |
| 1000 | 每批追加 8 节点 | 35.55 | 4.40 |
| 500 | 改一个节点位置 | 26.85 | 5.35 |
| 1000 | 改一个节点位置 | 31.00 | 4.45 |
| 500 | 平移视口提交 | 2.45 | 2.80 |
| 1000 | 平移视口提交 | 3.05 | 2.45 |

500/1000 节点初始场景均挂载 255 个节点；没有减少显示对象。25 次标题修改的节点函数调用总数从 6375 降至 50：修改的节点和直接引用它的节点各 25 次，其他节点无需重新渲染。空间索引构建从 25 次降至 0。追加场景计入预热和测量，最终分别为 724/1224 个节点，完整保留新增数据；新增对象位于屏外时，已挂载节点的测量期重渲染降至 0。

这是同步 React 更新提交的比较，**不包含完整页面、后端保存、媒体原图解码或原生客户端的交互帧率**。后台浏览器的 rAF 调度不稳定，没有用它声称达到 60fps。纯视口平移未证明稳定收益；主要收益发生在节点数据变化时。

独立 CPU 比较使用含长提示词与助手会话的固定数据、3 次预热和 51 次采样，前后交替执行。1000 节点约 4.29 MB 文档，末尾单节点变化的比较中位数从 4.90ms 降至 0.016ms；该数字也不是帧率或保存总时长。

## 正确性与限制

- 类型检查与前端精简构建通过。原有大分包提示保留。
- 素材引用、空间索引、文档合并、历史恢复和新回归测试：93 项通过。
- 保存/恢复浏览器场景：20 项通过，涵盖手动删除、重开、缺缓存、并发写入、生成状态和账号切换。
- 缩放、离开保存和网格：12 项通过；连接、选择、批量连接与跨浏览器定位：28 项通过。
- 回放比较了 10 种分组/批次折叠展开、父节点/类型变化、移动缩放尺寸、删除端点和排序场景，显示节点及连线端点与基线一致。明暗主题的 500 节点截图逐像素一致。

- 尚未进行 Mac WKWebView / Windows WebView2 的原生多节点对照、真实高分辨率媒体压力测试、真实付费 Agent 生成或正式安装包验收。没有替换本机正式应用或发布。

## 重跑

```sh
cd web
bun scripts/canvas-render-performance-server.ts before --base e13263c9 --build-only
bun scripts/canvas-render-performance-server.ts after --build-only
bun scripts/canvas-render-performance-server.ts after --serve
```

在同一个浏览器任务空间中依次访问服务打印的 `/before/?nodes=500` 与 `/after/?nodes=500`；等待 `window.__canvasPerf.ready`，先执行 `window.__canvasPerf.run("rename", 3)` 预热，再执行 `window.__canvasPerf.run("rename", 25)`。其他操作为 `append`、`move`、`pan`。服务只绑定回环地址，使用隔离的合成数据。计数插桩只存在于回放构建，不进入产品。

CPU 比较运行 `bun scripts/canvas-document-performance.ts`。相关回归运行 `bun test test/canvas-local-updates.test.ts test/canvas-resource-references.test.ts test/canvas-media-performance.test.ts test/canvas-spatial-index.test.ts test/canvas-document-rebase.test.ts test/canvas-history-restore.test.ts`。
