BeefTV 是一个本地优先的视频工作台：画布、素材和任务都留在你自己的电脑上，需要时再接自己的模型服务。这里是与代码一起维护的文档，按下面的分类查找。

## 产品概览

已实现的功能清单、可复现的制作案例，以及许可范围。第一条建议先看 [功能清单](./overview/features.mdx)，想知道实际能做出来什么就看 [Agent、Skills 与工作流案例](./overview/examples.mdx)。

## 开发文档

从零把后端与前端跑起来：[后端本地开发](./backend/local-development.mdx)。随包命令行工具的安装、连接和批量用法见 [beeftv 命令行基础使用](./backend/beeftv-cli.mdx)。要让外部程序读写本机工作区，看 [本地 HTTP API](./backend/http-api.mdx)；查代码位置和数据结构，看 [代码地图](./backend/code-map.mdx) 与 [后端数据库](./backend/backend-database.mdx)。

## 插件

插件系统、可用的界面扩展点，以及 AI 审美批改插件的工作方式，从 [插件系统](./plugins/plugin-system.mdx) 开始。
