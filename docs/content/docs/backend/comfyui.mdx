# 本机与自建 ComfyUI

BeefTV 可直接连接原生 ComfyUI。每个工作流保存为一个模型条目，用途可选图片、视频或音频。保存后，可在创作页和画布的模型选择器中使用。

## 准备服务

先在目标 ComfyUI 中安装工作流需要的 checkpoint、LoRA 和自定义节点，并确认工作流可以独立运行。BeefTV 读取已有模型选项，不负责安装节点或下载权重。

服务地址必须能从 BeefTV 后端访问。本机通常填写 `http://127.0.0.1:8188`。后端运行在容器或另一台机器时，`127.0.0.1` 指向后端所在环境，需要改成实际可达的 ComfyUI 主机。

本机和内网地址需要精确放行。在启动 BeefTV 后端的环境中设置以下变量，并重启后端或桌面应用：

```powershell
$env:CANVAS_ALLOWED_PRIVATE_UPSTREAM_HOSTS = "127.0.0.1"
```

变量只填写主机名或 IP，不带协议、端口和路径。多个可信主机用逗号分隔。填写 `127.0.0.1` 不会同时放行 `localhost` 或其他内网地址。HTTP 也需要精确放行；公网服务应使用 HTTPS。请求和媒体下载均拒绝重定向。

## 添加工作流

1. 打开设置中的“模型服务”，添加服务并选择 **ComfyUI**。
2. 填写连接名称和服务地址。无鉴权的本机服务可留空 API Key；填写后以 Bearer 认证发送。反向代理的其他认证可在高级设置中添加请求头。
3. 点击“配置工作流”，输入自定义名称并选择图片、视频或音频用途。
4. 点击该条目的“配置使用”，打开“ComfyUI 工作流”。导入 ComfyUI 导出的 **API 格式 JSON**，或粘贴后点击“应用 JSON 并识别输入”。
5. 核对字段来源和模型选项，完成后点击“保存并使用”。

导入接受节点 ID 到 `class_type`、`inputs` 的对象，也接受外层含 `prompt` 的请求对象。普通界面工作流的 `nodes/links` 格式不能执行。单个 JSON 最多 8 MiB，最多 4096 个节点。

导入会读取 `/object_info`，检查节点是否已安装，并获取 checkpoint、LoRA 等枚举与数值范围。这一步不会提交生成。连接失败时仍可保留有效 JSON；此时字段默认保留原值，需要手动绑定任务提示词与素材，或修复连接后重新应用 JSON。

“验证连接并刷新选项”保留已有字段映射。重新应用 JSON 则重新识别输入，覆盖该条目的旧映射。

工作流 JSON 和映射保存在本地后端加密的模型配置中，随启动恢复。所有服务与工作流的配置 JSON 合计最多 32 MiB，超限会拒绝保存。浏览器的 `localStorage` 只缓存模型条目与偏好，不复制这些大 JSON。

## 配置输入与输出

| 配置 | 行为 |
| --- | --- |
| 任务提示词 | 替换选定文本字段；自动识别优先使用正向条件，仍需核对自定义节点 |
| 保留工作流默认值 | 使用该字段保存的值，负向提示词可保留独立内容 |
| 参考图片、视频、音频或蒙版 | 读取任务中对应序号的素材，上传到目标 ComfyUI 的 `input/beeftv`，再填写服务器返回的文件名 |
| 宽度、高度、数量等 | 仅在显式绑定字段来源时使用任务参数；数字和布尔值保持 JSON 类型 |
| checkpoint、LoRA 等 | 读取目标服务实际提供的选项；选择所需值并启用该字段 |
| 随机种子 | 在配置范围内随机生成，最大值限制为 JavaScript 可精确表示的整数 `9007199254740991` |

工作流中的节点连接保持原样。映射不能覆盖连线输入。参考素材按现有资源归属规则读取，必填槽位缺失会阻止提交。图片、视频、音频加载节点需要接受上传后得到的文件名；自定义节点若要求其他路径或请求协议，需要自行调整工作流。

输出需要能在 ComfyUI `/history` 中提供文件描述。例如，图片使用 `SaveImage`，视频使用返回 MP4/WebM 文件的保存节点，音频使用 `SaveAudio` 等保存节点。支持读取 `images`、`gifs`、`videos`、`audio` 和 `audios` 列表，并按所选用途筛选 MIME 类型。视频和音频任务各取第一个匹配产物；图片任务收集匹配图片。仅有内存输出或外部链接的自定义节点不适用。

## 任务与排障

生成沿用 BeefTV 的持久任务链路：提交 `/prompt` 后保存 `prompt_id`，查询原任务的 `/history/{prompt_id}`，再通过 `/view` 读取媒体并保存到本地资源。恢复已受理任务时继续查询原编号，不重新提交生成。

如果提交结果不确定或受理回执无法保存，任务会进入现有的不确定提交处理，阻止自动重复生成。ComfyUI 清空历史后，BeefTV 无法凭原编号找回结果。取消本地等待不保证停止 ComfyUI 的上游执行；本接入不会调用可能中断其他任务的全局 `/interrupt`。

连接失败时先检查地址可达性、精确主机放行和鉴权。提示缺少节点时，在 ComfyUI 安装对应节点并重启。任务完成却没有媒体时，检查保存节点和工作流用途。点击“生成测试”会真实运行工作流；它与只读取节点信息的连接验证不同。
