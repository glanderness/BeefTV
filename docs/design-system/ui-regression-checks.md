# UI 防回退检查 v1

范围为画布外 UI。检查复用既有 AntD、PostCSS、组件样例和浏览器测试，不引入另一套组件框架或视觉快照平台。规则入口是 [检查脚本](../../scripts/check-outer-ui-contract.cjs)，实际结果见[阶段 4 验收记录](ui-system-stage4-regression-2026-10-30.md)。

## 开发者入口

在仓库根运行 `node scripts/check-outer-ui-contract.cjs`，只读扫描源码，失败时以非零退出并报告文件/行号或预算增长。扫描复用已有 [CSS 审计](../../scripts/audit-outer-ui-styles.cjs)，不读取提交后的清单来代替当前源码，不写文件、不删除规则。

在 `web/` 运行 `bun run test:ui-system`：共享控件、集合几何、状态样例、详情信息、模型凭据和存储表单的定向回归。新增 [治理测试](../../web/test/outer-ui-governance.test.ts)也会被现有 `bun run test` 自动发现；快速命令不替代全量测试或安装版实操。

## 样式所有者

| 角色 | 主要入口 | 约束 |
| --- | --- | --- |
| 导航、侧栏和页面壳 | workspace-navigation.css | 保护共享 shell、stage、sidebar/nav 及 link/title/icon；页面不能添加反向覆盖 |
| PageHeader 和页面内容容器 | workspace-page.css | 保护 app-page-header、title/actions 与 app-section-page-content；精调变体仍由该入口管理 |
| WorkspaceForm | workspace-controls.css / workspace-ui.css | 前者拥有字段适配，后者保留既有标签规则；不允许业务页覆写共享 form 作用域 |

仅登记两个组合场景：技能页分配固定页头/页签与可滚动内容的 flex 空间；新手引导按折叠导航调整自身入口。例外按文件、完整选择器、属性、值及非 important 精确匹配，不能借同一文件放开颜色、尺寸或边距覆盖。具体匹配写在检查脚本，与[布局治理](interface-and-style-governance.md)一起 review。

## 历史债务预算

冻结的是本集成工作区的既有状态，不表示这些规则都合理或已完成用户验收。当前 CSS 扫描为 27 文件，含 1,423 个 important 声明及 495 个重复候选组；混合 globals 的文件计数含画布规则，不能据此自动删除。

- `legacyBudgets` 按文件限制 important 数量和重复候选中的声明出现次数；未登记文件默认上限为零。
- 重复按相同条件、选择器分支和属性识别，深浅/断点/状态分支不会仅因同名属性被合并。跨文件候选也计入，不把扫描器当作最终级联计算器。
- 允许减少历史数量，不自动抬高上限；减少后应在同一经实操验收的迁移中收紧预算，避免留下空余额。
- 出现增长先回到所有者消除重复；确有第三方适配等必要情况，记录原因、适用边界、验收结果和移除条件，再交叉 review 后调整对应预算。禁止重跑清单或无说明增大数字来消除失败。

数量预算可能漏掉等量替换，不能自动理解“有无依据”；所有者检查也不解析完整 CSS 语义、变量、Tailwind/inline/JS 主题、选择器等价性或运行时可达性。它们是一道轻量检查，不是全站无 Bug 证明。颜色或全局风格调整仍应从语义 token/主题与所属入口修改，并执行实际 UI 验证。

## 固定回归清单

每次 UI 单项先查代码和最小充分测试，再在唯一安装版验证；记录 App 版本、主题、窗口、路径、结果和条件限制。

1. 首页：hero、能力入口、最近项目、导航与长名称；保留原精调比例。
2. 项目：页头、右侧动作、卡片与列表；搜索/返回、弹窗关闭及滚动边界。
3. 资产：页头、搜索/筛选、类型栏、网格/列表、分页和窄窗换行。
4. 当前变更页：标签/输入绑定、键盘、错误定位、busy/禁用、保存与返回、浮层和长内容。
5. 深浅主题、桌面/窄窗、窗口往返和滚动；查看是否黑底、重叠、溢出、残留遮罩或重复反馈。

涉及真实凭据、上传、迁移、清理或有费用的操作，保留独立授权和条件验收，不为通过外观检查执行这些动作。源码测试、隔离夹具、安装版自验、用户验收、PR 和合并分别登记到同一飞书总览，不能互相替代。
