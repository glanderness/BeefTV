# 存储设置 · 密码输入框高度修复

日期：2026-10-30。Lucas 在 3C-1 页面验收中指出 Secret Key 下方输入框高度异常。实际位于同页 F11“参考素材对象存储”的 Secret Access Key；作为独立可见 Bug 修复，不据此开展 F11 表单迁移，也不将未确认的 F10 改动混入未来同一提交。

## 根因与最小修复

安装版 2.0.5 可见密码外框偏高并有内层背景。测试先补齐实际 `.app-user-workspace`、`.app-product-workspace`、`.settings-page` 作用域和共享控件主题，复现 1440/390px、深浅四组：普通框 38px，密码框 50px，内部背景不透明，四项高度断言均失败。

`globals.css` 中既有设置页规则同时匹配 `.ant-input-affix-wrapper` 外框及其内部 `.ant-input`；内部也得到最小高度 34px、背景、边框/圆角和焦点规则，撑高复合控件。仅在原有四处选择器中排除 affix 的直接内部 input；保留原声明值、普通输入及外框样式，未增加覆盖规则、important 或固定高度。

未修改 ReferenceStoragePane 的字段、secret/config 状态、保存、测试上传或任何接口。该业务功能的共享表单迁移仍留到独立的 3C-2。
